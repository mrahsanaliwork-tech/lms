# LMS Platform

A full-featured Learning Management System built with Laravel 12, Vue 3, and Inertia.js.

---

## Tech Stack

| Layer        | Technology |
|-------------|------------|
| Backend      | PHP 8.2 · Laravel 12 |
| Frontend     | Vue.js 3 · Inertia.js · Tailwind CSS v4 |
| Database     | MySQL (via XAMPP) |
| Auth         | Laravel Sanctum · Spatie Permissions |
| Payments     | Stripe (tokenised — no raw card data stored) |
| AI           | OpenAI API (chat tutor, quiz generation, content summarisation) |
| PDF export   | barryvdh/laravel-dompdf v3 |
| CSV export   | League/CSV v9 |
| Charts       | vue-chartjs v5 + Chart.js v4 |
| Queue/Worker | Laravel Horizon (4 supervisors) |
| Real-time    | Laravel Echo · Pusher (optional) |

---

## Key Features

### For Students
- Enrol in free and paid courses (Stripe checkout)
- Full-screen course player with video, PDF, and text lessons
- Mark lessons complete with automatic progress tracking
- Take timed quizzes with instant results
- Submit assignments and receive grades
- AI Tutor — ask questions about any lesson
- Earn and download PDF certificates on course completion
- Dashboard with continue-learning, deadlines, and quiz results

### For Instructors
- Create and manage courses, modules, and lessons
- Build quizzes with MCQ and true/false questions
- Create assignments with file-upload submissions
- Grade student submissions
- AI-assisted quiz and description generation
- Course analytics

### For Admins
- Full user, course, and organisation management
- Course approval workflow (pending → approved → published)
- Reports: student performance, revenue, course analytics, quiz stats, AI usage
- CSV and PDF export for all reports
- Activity log for all state-changing admin actions
- Laravel Horizon dashboard (`/horizon`) — queue monitoring

## Installation

### Prerequisites
- PHP 8.2+ with extensions: pdo_mysql, mbstring, openssl, tokenizer, xml, ctype, json, bcmath, fileinfo
- Composer 2
- Node.js 20+ and npm
- MySQL 8+ (or MariaDB)
- XAMPP (or equivalent local server)

### Steps

```bash
# 1. Clone the repository
git clone <repo-url> lms-platform
cd lms-platform

# 2. Install PHP dependencies
composer install

# 3. Install JS dependencies
npm install

# 4. Copy and configure environment
cp .env.example .env
php artisan key:generate

# 5. Configure your .env (see section below)

# 6. Run migrations
php artisan migrate

# 7. Seed the database
php artisan db:seed

# 8. Create storage symlink
php artisan storage:link

# 9. Build frontend assets
npm run build
# or for development:
npm run dev

# 10. Start the server
php artisan serve
```

## Environment Variables

Copy `.env.example` to `.env` and set the following:

```env
# App
APP_NAME="LMS Platform"
APP_ENV=local
APP_KEY=                          # generated by php artisan key:generate
APP_DEBUG=true
APP_URL=http://localhost:8000

# Database
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=lms_platform
DB_USERNAME=root
DB_PASSWORD=

# Cache & Queue (use 'database' for local dev, 'redis' for production)
CACHE_STORE=database
QUEUE_CONNECTION=database
SESSION_DRIVER=database

# Redis (required for Horizon in production)
REDIS_HOST=127.0.0.1
REDIS_PASSWORD=null
REDIS_PORT=6379

# Mail
MAIL_MAILER=log                   # use 'smtp' in production
MAIL_HOST=smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=
MAIL_PASSWORD=
MAIL_FROM_ADDRESS="no-reply@lms.com"
MAIL_FROM_NAME="${APP_NAME}"

# Stripe (for payments)
STRIPE_KEY=pk_test_...
STRIPE_SECRET=sk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...

# OpenAI (for AI tutor, quiz generation, content summaries)
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-mini

# Pusher (optional, for real-time notifications)
PUSHER_APP_ID=
PUSHER_APP_KEY=
PUSHER_APP_SECRET=
PUSHER_APP_CLUSTER=mt1

VITE_PUSHER_APP_KEY="${PUSHER_APP_KEY}"
VITE_PUSHER_APP_CLUSTER="${PUSHER_APP_CLUSTER}"

# AWS S3 (optional, for file storage in production)
AWS_ACCESS_KEY_ID=
AWS_SECRET_ACCESS_KEY=
AWS_DEFAULT_REGION=us-east-1
AWS_BUCKET=
```

## Security Notes

- Raw card details are never stored. Stripe tokens only.
- All file uploads are validated by MIME type and size.
- Admin actions are logged via `LogAdminActivity` middleware.
- Login is rate-limited to 5 attempts/minute per IP.
- AI endpoints are rate-limited to 20 requests/minute per user.
- CSRF protection is enforced on all state-changing routes.
- Role-based access is enforced by Spatie Permissions + Gate Policies.
